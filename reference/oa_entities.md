# Available entities in the OpenAlex database

Available entities in the OpenAlex database

## Usage

``` r
oa_entities()
```

## Value

Character vector of 5 entity options.

## Examples

``` r
oa_entities()
#> [1] "works"        "authors"      "institutions" "concepts"     "keywords"    
#> [6] "funders"      "sources"      "publishers"   "topics"      
```
