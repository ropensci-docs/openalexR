# Coverage of OpenAlex entity fields after converting to data frame.

List with 8 elements associated with 8 OpenAlex entities.

## Usage

``` r
oa2df_coverage
```

## Format

Each element is a data frame with 3 columns

- original:

  original field name from OpenAlex

- oa2df:

  new column name in output data frame from oa2df

- comment:

  additional notes
