# Index of Countries and their alpha-2 and alpha-3 codes.

Data frame contains the list of countries and their alpha-2 and alpha-3
codes.  

## Usage

``` r
countrycode
```

## Format

A data frame with 250 rows and 3 variables:

- Country:

  country names

- Alpha2:

  countries' alpha-2 codes

- Alpha3:

  countries' alpha-3 codes
